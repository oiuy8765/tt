什么在涨，而且现在还来得及

榜单基于 Google Trends 的搜索热度——也就是真实用户在 Google 上搜什么、搜得多不多， 只收搜索量持续上升的产品、品类、服务、工具，不是新闻热搜。所以这里问的不是「今天发生了什么」， 而是「未来半年什么会更好卖」。 每条话题都带 22 年月度历史曲线，增速、季节性、波动、是否已过峰，都是按曲线算出来的； 你还可以自己选一段时间（近 1、3、6、12、24 个月），只看这段时间里确实在涨的词。

这些标签和分数是怎么算出来的？（建议看一眼，避免误判）

先选载体，再看分数——因为「适合做站」和「适合选品」是两个完全不同的判断标准，同一个词在两边的排名会差很远。

观察窗口：选「近 6 个月」，就是把最近 6 个月的月均热度，和再往前 6 个月比，只留涨幅 > 0 的话题，并按这个涨幅排序。历史长度不足两倍的词会被排除（不拿半段数据下结论）。这也是为什么同一个词，换窗口后排名会变。

数字机会分（网站/APP/SaaS）= 0.38×90天增长 + 0.24×规模(3千~10万) + 0.18×变现 + 0.20×线上可行度

  • 线上可行度：关键词里有没有产品意图（app/tool/generator…）、品类能不能纯线上交付、描述里是不是在讲软件。命中实物词会大幅扣分。
  • 为什么规模甜点区比选品低：B 端词的搜索量天然小，3 千~10 万才是线上产品的舒适区。

实体机会分 = 0.35×增长 + 0.25×规模(2万~20万) + 0.20×变现 + 0.20×社媒

  • 变现：按类目推断的广告价值（金融/法律/软件高，娱乐/社交低）。这是推断值，不是实测 CPC，公开趋势数据里不含广告出价。
  • 社媒：8 个平台提及量总和，代表有没有真实人群在讨论。点开卡片能看到主战场在哪个平台。

建站适配度 = 0.30×12个月增速 + 0.30×规模(5千~10万长尾甜点) + 0.18×稳定性 + 0.12×新鲜度 + 0.10×内容可覆盖性

  • 做站要的是「能长期吃搜索流量的长尾词」，大词反而抢不过头部站。稳定性用近 24 个月环比波动衡量：忽高忽低说明是事件驱动，不是稳定需求。

四个判定标签，全部来自 Google Trends 历史曲线与收录时间：

  • 真伪爆发：把 24 / 60 / 120 / 180 个月四个时间尺度分别判断是否「爆发」。四个都在爆 = 长期结构性；只有最近 24 个月在爆 = 短期热点，容易踩坑。
  • 阶段：结合峰值偏离、连续下滑月数和爆发判定，给出「长期增长 / 新兴起势 / 高位平台 / 连续回落 / 已过峰」。
  • 窗口期：这条话题上榜多久了。刚收录 < 3 个月是最好的卡位期，超过 2 年基本已被充分开发。
  • 季节：最近 36 个月按日历月归一化后取平均，得到 12 个月的相对强弱。强度 < 0.4 视为全年平坦，不建议当季节性品类做。

分数只做初筛，不能替代商业判断。真正的可行性还要自己看竞争程度、供应链、合规（医疗/金融/博彩尤其注意）和你的执行能力。

这个站解决什么问题

大多数人打开 Google Trends 只看 Trending Now，挖到一堆新闻热点，然后踩坑——那些词两天就没了，没法做产品。 这个站做的是另一件事：把 Google Trends 里「已经在涨的搜索需求」筛出来，判断它适合做什么——做站、选品、投放还是做内容。

  • 不是新闻榜：每日热榜单独放在一个页面，明确标注「新闻向」，避免和机会库混在一起。
  • 先选载体再看分数：网站/APP 和实体产品的判断标准不同，分开算分。
  • 能看出真假：四个时间尺度交叉验证，把「只有最近两年在爆」的短期热点标出来。

怎么用（三步）

  1. 先选载体：网站 / APP / SaaS，还是实体产品。这一步决定了后面所有分数按哪套标准算。
  2. 再选时间窗口：想抓刚起来的短波，选「近 1~3 个月」；想找能长期做的，选「近 12~24 个月」。不选就是全量。
  3. 最后看四个标签：阶段、真伪爆发（几个时间尺度都在涨）、窗口期（被收录多久）、季节（什么时候备货）。

已知限制（如实说明）

  • 月搜索量是按 Google Trends 相对热度换算的估算值，量级可信、具体数字有误差，不是官方精确值。
  • 广告出价（CPC）拿不到，界面里的「变现」分是按类目推断的，只能横向比较。
  • 历史曲线是月粒度，所以「近 3 个月」是最近 3 个月均值对比之前 3 个月，不是逐日数据。
  • 榜单本身只收「已经在涨的话题」，整体增长率天然偏高，别把 +200% 当成异乎寻常。
  • 「载体」「形态」是按关键词和类目规则推断的，少数词会分错，以你自己的判断为准。
  • 所有分数只做初筛，替代不了商业判断：竞争、供应链、合规（医疗/金融/博彩尤其）都要自己核。
